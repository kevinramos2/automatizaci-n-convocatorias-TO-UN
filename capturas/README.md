# Capturas

Imágenes del panel para el README y el portafolio. Antes de agregar una captura aquí:

- Ningún nombre, cédula, documento o fila del Sheet real debe ser visible — usar un expediente
  de prueba con datos inventados, o censurar (recuadro negro sólido, no solo difuminado) sobre
  cualquier dato real que aparezca en pantalla.
- Preferir capturas del flujo (lista de aspirantes, un paso de la revisión, el resumen final)
  antes que de una sola pantalla suelta.
